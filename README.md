# Planeación Agregada

Modelo MILP multietapa, multifuente y multiproducto con escasez, con interfaz gráfica en Google Colab.

[![Abrir en Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/justkousei/Planeacion-Agregada/blob/main/planeacion_agregada.ipynb)

## Uso
1. Abre el cuaderno en Colab con el botón de arriba.
2. Ejecuta todas las celdas (Entorno de ejecución → Ejecutar todo).
3. Define productos, etapas, fuentes y períodos → **Generar tablas** → edita los datos → **RESOLVER**.
